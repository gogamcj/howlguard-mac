# HowlGuard 사용 설명서 (macOS)

HowlGuard는 마이크 신호에서 하울링(피드백)을 실시간으로 찾아내고, 그 주파수만 아주 좁은 노치 필터로 깎아 내는 맥용 프로그램입니다. Apple Silicon(M1~M4)과 Intel 맥 모두에서 돌아가며 macOS 11 이상이 필요합니다. 지연이 없는 필터(IIR)만 쓰므로 소리가 늦어지지 않고, 감지는 별도 스레드에서 돌아갑니다.

- `HowlGuard.app` : 단독 실행 프로그램 (오디오 인터페이스나 콘솔 USB에 직접 연결)
- `HowlGuard.vst3` : VST3 플러그인 (예: Reaper, Gig Performer, Cubase)
- `HowlGuard.component` : Audio Unit 플러그인 (예: Logic Pro, MainStage, GarageBand)
- `install_plugins.command` : 두 플러그인을 설치해 주는 스크립트

## 1. 설치

1. `HowlGuard.app`을 **응용 프로그램** 폴더로 옮깁니다.
2. 처음 열 때 "확인되지 않은 개발자" 경고가 나오면 앱을 **오른쪽 클릭(또는 control+클릭) → 열기 → 열기**를 누르세요. 코드 서명(공증)이 안 된 프로그램이라 나오는 경고이고, 한 번만 하면 됩니다. macOS 15 이상에서 "열기" 버튼이 안 보이면 **시스템 설정 → 개인정보 보호 및 보안** 아래쪽의 **그래도 열기**를 누릅니다.
   - 그래도 열리지 않으면 터미널에서 `xattr -dr com.apple.quarantine /Applications/HowlGuard.app` 을 한 번 실행하세요.
3. 처음 실행하면 **마이크 접근 허용**을 묻습니다. 반드시 **허용**을 눌러야 오디오 입력이 들어옵니다. 실수로 거부했다면 **시스템 설정 → 개인정보 보호 및 보안 → 마이크**에서 HowlGuard를 켜세요.
4. 플러그인으로 쓰려면 `install_plugins.command`를 더블클릭합니다(처음엔 오른쪽 클릭 → 열기). 직접 복사해도 됩니다.
   - VST3: `~/Library/Audio/Plug-Ins/VST3/`
   - AU: `~/Library/Audio/Plug-Ins/Components/`
   - 복사한 뒤 호스트에서 플러그인을 다시 스캔합니다.

## 2. 콘솔에 연결하기

HowlGuard는 하울링을 없애고 싶은 **신호의 경로 중간**에 들어가야 합니다. 대표적인 연결은 세 가지입니다.

| 연결 방법 | 신호 흐름 | 쓰는 곳 |
|---|---|---|
| 디지털 콘솔 USB (X32, Wing, TF, SQ, DM 등) | 마이크 채널 → USB 출력 N → 맥 입력 N → HowlGuard → 맥 출력 N → USB 입력 N → 콘솔 채널(또는 인서트 리턴) | 보컬, 강연 마이크 채널 |
| 아날로그 콘솔 인서트 | 채널 인서트(Y 케이블) Send → 인터페이스 입력 → HowlGuard → 인터페이스 출력 → 인서트 Return | 채널 하나 |
| 버스 출력 | 메인 L/R 또는 모니터 버스 출력 → 인터페이스 → HowlGuard → 인터페이스 → 앰프/파워드 스피커 | 메인 스피커, 모니터 웨지 |

**마이크 한 채널에 넣는 것이 가장 효과적입니다.** 하울링은 마이크가 스피커 소리를 다시 받아서 생기므로, 하울링이 잘 나는 마이크 채널에 직접 거는 것이 다른 소리를 덜 건드립니다.

스테레오(2채널)로 연결하면 두 채널을 합쳐 감지하고 같은 노치를 양쪽에 똑같이 적용합니다. 모노 입력에 스테레오 출력을 고르면 같은 신호가 양쪽으로 나갑니다.

### 여러 마이크를 한 번에 (멀티채널)

단독 실행 앱은 **최대 16채널을 채널마다 따로** 처리합니다. 채널마다 감지기, 노치 32개, 모드와 노브 설정이 각각 있습니다.

- [오디오 설정]에서 켠 **입력 n번째 채널은 처리된 뒤 출력 n번째 채널로** 나갑니다. 예를 들어 입력 1~8을 켜고 출력 1~8을 켜면 8채널이 각각 처리됩니다.
- 창 맨 위의 **채널 탭**을 눌러 채널을 고르면 아래 화면이 그 채널의 설정으로 바뀝니다.
- 탭의 점은 초록색이면 정상, **빨간색이면 그 채널에서 울림을 지켜보는 중**, 회색이면 바이패스입니다. 오른쪽 숫자는 활성 노치 수입니다.
- 탭을 **더블클릭**하면 채널 이름(예: 보컬 1, 사회자)을 바꿀 수 있습니다.
- 설정은 채널별로 자동 저장됩니다. 베뉴 저장/불러오기는 지금 고른 채널 하나에 대해 동작합니다.
- VST3/AU 플러그인은 지금처럼 꽂힌 채널 하나(모노 또는 스테레오 링크)만 처리합니다.

### 베링거 WING / WING Compact에 연결하기

WING은 USB 오디오로 48채널을 주고받을 수 있어 케이블 하나로 여러 마이크를 처리할 수 있습니다. (메뉴 이름은 펌웨어 버전에 따라 조금 다를 수 있습니다.)

1. 맥에서는 드라이버가 필요 없습니다(USB 클래스 컴플라이언트). USB로 연결하면 **오디오 MIDI 설정** 앱에 WING이 보입니다.
2. **콘솔 → 맥** : 라우팅의 출력(Outputs) 화면에서 USB 출력 1, 2, 3...에 처리할 마이크의 소스(로컬 입력 프리앰프 또는 채널 다이렉트 아웃)를 차례로 지정합니다.
3. **맥 → 콘솔** : 처리할 각 채널의 입력 소스(Main source)를 USB 입력 1, 2, 3...으로 바꿉니다. 그러면 채널 N은 HowlGuard를 거친 소리를 받습니다.
4. HowlGuard [오디오 설정]에서 장치 종류를 **CoreAudio**, 입력/출력 장치를 WING으로 고르고, 입력과 출력을 같은 개수(예: 1~8)만큼 켭니다. 샘플레이트는 48 kHz, 버퍼는 64나 128을 권장합니다.
5. 콘솔 프리앰프 게인은 그대로 콘솔에서 조절하고, HowlGuard 입력 미터가 빨간 칸에 닿지 않는지 확인합니다.

맥을 거쳐 돌아오므로 채널마다 몇 ms(버퍼 64에서 대략 3~6 ms)의 지연이 생깁니다. 같은 소리를 콘솔에서 직접 받는 다른 채널과 섞으면 소리가 겹쳐 이상해질 수 있으니, 처리할 마이크는 HowlGuard를 거친 경로 하나로만 쓰세요. 맥이 멈추거나 잠자기에 들어가면 그 채널 소리도 끊기므로 공연 전에 충분히 시험해 보세요.

## 3. 오디오 설정

오른쪽 위 **[오디오 설정]**을 누릅니다.

1. **Audio device type** : 맥에서는 `CoreAudio` 하나만 있습니다. 지연이 짧아서 ASIO 같은 별도 드라이버가 필요 없습니다.
   - 입력과 출력이 서로 다른 장치라면(예: 입력은 콘솔 USB, 출력은 다른 인터페이스) 맥의 **오디오 MIDI 설정** 앱에서 **통합 기기(Aggregate Device)**를 만들어 하나로 묶은 뒤 그 장치를 고르면 안정적입니다.
2. **입력/출력 장치와 채널** : 콘솔에서 보낸 채널과 받을 채널을 체크합니다 (최대 16개, 입력 n번 → 출력 n번).
3. **Sample rate** : 콘솔과 같은 값 (보통 48000 Hz).
4. **Audio buffer size** : 64 또는 128 샘플을 권장합니다. 소리가 끊기면 한 단계 올리세요.

화면 위쪽에 현재 장치와 대략의 왕복 지연(ms)이 표시됩니다. 설정은 자동 저장되어 다음 실행 때 그대로 열립니다(`~/Library/Application Support/HowlGuard.settings`).

**잠자기 방지** : 공연 중에 맥이 잠자기에 들어가면 소리가 끊깁니다. 전원 어댑터를 연결하고 **시스템 설정 → 잠금 화면/디스플레이**에서 잠자기를 꺼 두세요.

## 4. 화면과 조작

### 모드 (위쪽 왼쪽 버튼)

| 모드 | 용도 | 특징 |
|---|---|---|
| 스피치 | 강연, 설교, 사회자 | 빠르게 반응 (약 0.2초 확인) |
| 노래 | 보컬 | 지속음과 비브라토를 하울링으로 오인하지 않도록 더 오래 확인 (약 0.3초) |
| 멀티 | 악기, 밴드, 여러 소스가 섞인 채널 | 가장 신중함 (약 0.45초) |
| 모니터 | 모니터 웨지, 인이어 아닌 바닥 스피커 | 가장 빠르고 공격적 |

어느 모드든 **빠르게 커지는 순음**(하울링이 막 시작되는 모양)은 확인 시간을 기다리지 않고 바로 잡습니다.

### 오른쪽 노브

- **강도** : 노치 하나가 깎을 수 있는 최대 깊이(최대 -30 dB)와 한 번에 깎는 양. 기본 75%.
- **감도** : 높을수록 작은 울림도 빨리 잡습니다. 너무 높이면 음악의 지속음까지 깎을 수 있습니다. 기본 50%.
- **복원 시간** : 자동 노치가 6 dB 풀리는 데 걸리는 시간. 하울링이 멈추고 3초가 지나면 천천히 풀리기 시작합니다. 1분 안에 같은 주파수가 다시 울리면 더 빨리, 지난번 깊이로 다시 잡습니다.
- **노치 폭** : 좁게(1/40 옥타브), 보통(1/20), 넓게(1/10). 좁을수록 음색 변화가 적습니다.

### 스펙트럼 화면

- 회색 선은 입력, 파란 선은 출력 스펙트럼입니다.
- 위쪽의 동그라미와 세로 막대가 노치입니다. 막대가 길수록 깊게 깎은 것입니다. **파란색은 자동 노치, 주황색은 고정 노치**입니다.
- 주황색 곡선은 모든 노치를 합친 EQ 곡선입니다(오른쪽 눈금).
- 빨간 세로선은 지금 울림이 의심되어 지켜보는 주파수입니다.
- 노치 위에 마우스를 올리면 주파수와 깊이가 보이고, **오른쪽 클릭**으로 삭제하거나 고정/해제할 수 있습니다.
- [스펙트럼] [노치] [둘 다] 버튼으로 보기 방식을 바꿉니다.

### 아래쪽

- **활성 노치** : 사용 중인 노치 수(최대 32)와 그중 고정 노치 수.
- **울림 감지** : 지켜보는 주파수. 없으면 "없음".
- **입력/출력 미터** : -60 ~ 0 dBFS. 빨간 칸이 켜지면 입력이 너무 큽니다. 콘솔에서 보내는 레벨을 낮추세요.
- **베뉴 저장/불러오기** : 설정과 노치(고정 노치 포함)를 공연장별 파일(`.howlvenue`)로 저장합니다. 기본 폴더는 `문서/HowlGuard Venues` 입니다. 맥 버전은 새로 만든 것이라, 윈도우 버전에서 저장한 베뉴 파일은 열리지 않을 수 있습니다.
- **A / B, 복사** : 설정 두 벌을 오가며 비교합니다.

### 컴프레서

노치 필터 다음에 컴프레서가 있습니다. 채널마다 따로 설정됩니다. **컴프레서 켜기**를 누르면 동작하고, 막대를 좌우로 끌어 값을 바꿉니다(더블클릭하면 기본값).

- **스레숄드** (-60 ~ 0 dB, 기본 -20) : 이 레벨을 넘는 소리부터 줄입니다.
- **비율** (1:1 ~ 20:1, 기본 3:1) : 3:1이면 스레숄드를 3 dB 넘은 소리를 1 dB만 넘게 줄입니다. 말소리는 2:1~4:1이 무난합니다.
- **어택** (0.1 ~ 100 ms, 기본 5) : 커진 소리를 줄이기 시작하는 속도.
- **릴리즈** (10 ~ 2000 ms, 기본 150) : 작아진 뒤 원래대로 돌아오는 속도.
- **메이크업** (0 ~ 24 dB, 기본 0) : 줄어든 만큼 다시 올리는 게인.
- **게인 리덕션** 미터는 지금 몇 dB를 줄이고 있는지 보여 줍니다.

**주의:** 컴프레서는 작은 소리를 상대적으로 키우기 때문에 하울링이 나기 쉬워집니다. 메이크업 게인은 꼭 필요한 만큼만 올리고, 올린 뒤에는 링아웃을 다시 해 보세요. 바이패스를 켜면 노치와 컴프레서가 모두 꺼집니다.

### 위쪽 버튼

- **바이패스** : 노치와 컴프레서를 끄고 원음을 내보냅니다. 감지는 계속되므로 노치가 쌓이는 것은 볼 수 있습니다.
- **링아웃** : 공연 전 시스템 튜닝용입니다(아래 5번).
- **모두 고정** : 지금 있는 자동 노치를 전부 고정 노치로 바꿉니다.
- **지우기** : 자동 노치만 지우거나, 고정 노치까지 전부 지웁니다.

## 5. 공연 전 링아웃 순서 (추천)

1. 마이크를 실제 공연 위치에 두고, 스피커와 모니터를 공연 때처럼 켭니다.
2. HowlGuard에서 **링아웃**을 켭니다.
3. 콘솔에서 해당 채널 게인(또는 페이더)을 **천천히** 올립니다. 울림이 시작되면 HowlGuard가 바로 잡고, 잡힌 노치는 **주황색 고정 노치**가 됩니다.
4. 원하는 최대 음량보다 3~6 dB 높은 곳까지 올린 다음 다시 공연 레벨로 내립니다. 고정 노치는 보통 4~8개면 충분합니다. 너무 많으면 소리가 얇아지니 그 전에 멈추세요.
5. **링아웃**을 끄고 **베뉴 저장**을 누릅니다.
6. 공연 중에는 남은 자동 노치가 새 하울링을 잡습니다.

## 6. 알아 둘 것

- 피드백 억제기는 시스템 이득을 보통 3~9 dB 더 확보해 주는 도구입니다. 스피커와 마이크 위치, 지향성, 콘솔 EQ가 먼저입니다.
- 감도와 강도를 지나치게 올리면 음색이 변할 수 있습니다. 노래나 악기 채널은 **노래**나 **멀티** 모드를 쓰세요.
- 감지에 쓰는 분석 창은 약 170 ms입니다. 시작부터 아주 빠르게 폭주하는 하울링은 잡히기 전에 짧게 들릴 수 있으며, 링아웃으로 미리 고정해 두면 이것을 막을 수 있습니다.
